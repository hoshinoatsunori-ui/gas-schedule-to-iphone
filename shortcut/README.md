# iPhoneショートカット「予定追加」の作り方

メールの「iPhoneに登録」ボタン（リンク）を受け取り、今週の予定一覧から選んだものをiPhoneのカレンダーにまとめて登録するショートカットです。

> アクション名は作者の環境（日本語表示のiPhone）での表記です。iOSのバージョンによって表記が異なる場合は、括弧内の英語名や「辞書」「Base64」「置き換え」などのキーワードで検索してください。

## 完成形

```text
[共有シートから テキスト・URL を受け取る]  もし入力がない場合：クリップボードを取得
テキストを照合         ショートカットの入力 で (?<=WKSCHED)[A-Za-z0-9_]+ に一致
テキストを置き換える   一致 の _p を + に置き換え
テキストを置き換える   アップデートされたテキスト の _s を / に置き換え
Base64エンコード       モード：デコード ／ 入力：アップデートされたテキスト
入力から辞書を取得
変数を設定             全体
辞書の値を取得         全体 内の labels
リストから選択         複数を選択：オン
変数を設定             選択
辞書の値を取得         全体 内の events
変数を設定             予定一覧
各項目を繰り返す       選択
│ 辞書の値を取得       予定一覧 内の [繰り返し項目]
│ 変数を設定           予定
│ 辞書の値を取得       予定 内の t → 変数を設定 タイトル
│ 辞書の値を取得       予定 内の s → 変数を設定 開始文字
│ 辞書の値を取得       予定 内の e → 変数を設定 終了文字
│ 辞書の値を取得       予定 内の a → 変数を設定 終日フラグ
│ 辞書の値を取得       予定 内の l → 変数を設定 場所
│ 入力から日付を取得   開始文字 → 変数を設定 開始日時
│ 入力から日付を取得   終了文字 → 変数を設定 終了日時
│ テキスト             [終日フラグ]
│ If文                 テキスト が次と等しい 1
│   予定を追加         開始日時〜終了日時 / タイトル / 場所 / 終日：オン
│ その他の場合
│   予定を追加         開始日時〜終了日時 / タイトル / 場所 / 終日：オフ
│ If文の終了
繰り返しの終了
通知を表示             登録しました
```

## 手順

### 1. 作成と共有シートの設定

1. 「ショートカット」アプリで「＋」→ 名前を **予定追加** にする
2. 画面下部の ⓘ（詳細）→ **「共有シートに表示」をオン**
3. 先頭に出る「共有シートから〜を受け取る」ブロックで
   - 受け取る種類：**テキスト** と **URL** だけをオン
   - 「もし入力がない場合」：**クリップボードを取得**

これで、メールのボタンを長押し →「共有…」から起動したときはリンクが、ホーム画面や背面タップから起動したときはクリップボードが入力になります。

### 2. 登録データの復元

4. 「テキストを照合」（Match Text）
   - テキスト：「ショートカットの入力」
   - パターン：`(?<=WKSCHED)[A-Za-z0-9_]+`
5. 「テキストを置き換える」（Replace Text）：`_p` → `+`（対象：一致）
6. 「テキストを置き換える」：`_s` → `/`（対象：アップデートされたテキスト）
7. 「Base64エンコード」：モードを **デコード** に変更（入力：アップデートされたテキスト）
8. 「入力から辞書を取得」→「変数を設定」で **全体** と名付ける

### 3. 一覧から選ぶ

9. 「辞書の値を取得」：キー `labels`、辞書は変数「全体」
10. 「リストから選択」：「＞」を開いて **複数を選択** をオン（任意で「すべてを選択」もオン）
11. 「変数を設定」：**選択**
12. 「辞書の値を取得」：キー `events`、辞書は変数「全体」→「変数を設定」：**予定一覧**

### 4. 繰り返して登録

13. 「各項目を繰り返す」：入力は変数「選択」
14. 繰り返しの中に、上の「完成形」のとおりにアクションを並べる
    - 1つ目の「辞書の値を取得」は、キー欄に変数「繰り返し項目」、辞書欄に「予定一覧」を指定
    - t, s, e, a, l の「辞書の値を取得」は、辞書欄をすべて変数 **予定** にする
    - 「変数を設定」の入力は、いずれも直前のアクションの出力を選ぶ
15. 「予定を追加」は「＞」を開いて、場所＝変数「場所」、終日のオン／オフを設定する
16. 「繰り返しの終了」の下に「通知を表示」

## つまずきやすい点

| 症状 | 原因 |
|---|---|
| 一覧が出ずに終わる | キー名の打ち間違い（`labels` / `events` は複数形） |
| 全件が同じ内容で登録される | t, s, e, a, l の「辞書」欄が「予定」になっていない |
| 「開始日が正しくありません」 | 「変数を設定」の入力が直前の出力ではなく、別の変数を指している |
| 「が次と等しい」が選べない | 数値として扱われている。一度「テキスト」アクションに通してから比較する |

途中の値は「結果を表示」アクションを差し込むと確認できます。

## 配布

完成したショートカットは、編集画面の共有ボタン →「iCloudリンクをコピー」で配布できます。受け取った側は、リンクを開いて「ショートカットを入手」を押すだけで追加できます。
